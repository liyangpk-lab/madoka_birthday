欢迎来到鲇川圆（Ayukawa Madoka）生日纪念板！这是一个充满温馨回忆的互动天地，您可以通过以下方式参与庆生：

🎹 留声机音乐：拉开侧边手账，选择您喜爱的《橙路》经典MIDI背景乐，调节音量或暂停。
✍️ 拖拽与排版：海报上的所有照片、留言、便签，都支持鼠标或手机直接拖动摆放。
🔄 角度与大小：鼠标悬停在任意照片或便签上，右上角是旋转手柄，右下角是缩放手柄，左上角可以撕下（删除）它。
📝 快速贴上：在海报的任意空白处双击，即可直接在该位置粘贴留言或粉丝贺图。
🎨 手账控制板：拉开左侧手账，可以发表留言、选择手写字体与颜色、或者贴上本地贺图（自动转为拍立得相片）。
📱 自适应缩放：在手账板中可切换“自适应屏幕宽度”或“1:1原始超清尺寸”。
